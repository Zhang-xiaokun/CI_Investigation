This is the data used in our work to examine collaborative information within recommender systems, including six datasets.
In each dataset,

  all_xxx.txt contains all user-item interaction sequences in test (all_test.txt), train (all_train.txt) and their combnation (all_seqs.txt).
  
  prediction.txt contains all top-20 prediction lists for a recommnendation method within the dataset.
  
  test1.txt contains the test sample, where the label item has a 0-hop CR with at least one item in the sequence, while testnd.txt indicates the label item does NOT hold the 0-hop CR with any items in the sequence.
  
  tests1.txt means the pure sample, where the sequence only contains one single type of CR.
